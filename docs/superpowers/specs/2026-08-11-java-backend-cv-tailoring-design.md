# Java Backend CV Tailoring Design

## Objective

Rewrite Nguyen Dang Khoi's English CV for the supplied Java back-end role while keeping every claim accurate and improving ATS keyword alignment.

## Editorial Direction

Use an ATS-first, project-forward structure. Present the candidate as a junior Java back-end engineer with relevant internship and substantial hands-on project experience. Do not imply two to three years of professional Java employment or experience with US customers unless the candidate later confirms it.

## Structure

1. Name, target title, location, phone, email, LinkedIn/GitHub if available.
2. Three-line professional summary focused on Java, Spring Boot, REST APIs, relational databases, security, and distributed systems.
3. Technical skills ordered to match the job description.
4. Professional experience with three concise, outcome-oriented AWS internship bullets.
5. Projects, led by E-commerce Microservices Platform and Vehicle Rental Platform; Crypto Market Alert Bot remains a shorter supporting project.
6. Education and English proficiency.

## Content Rules

- Use `Java Backend Developer` as the target title.
- Emphasize Java Core, OOP, Spring Boot, REST API design, SQL, authentication, error handling, Git, debugging, and maintainable code where supported.
- Include Java Core, OOP, design patterns, Maven, JPA/Hibernate, and testing only when supported by the candidate's work or repository.
- Preserve verified project technologies such as Kafka, PostgreSQL, Redis, Elasticsearch, Docker Compose, API Gateway, Eureka, JWT/OAuth2, and React/Vite.
- State English as `TOEIC 780`; do not label it fluent or claim professional customer communication without evidence.
- Avoid unsupported metrics and responsibilities.
- Remove date of birth and AI assistants from the main skills section.
- Normalize punctuation, spacing, capitalization, dates, and GitHub link labels.

## Length and Style

Target one dense page where formatting permits, otherwise no more than two pages. Use plain ATS-readable section headings, no tables, icons, columns, skill bars, photographs, or decorative graphics. Bullets should begin with strong verbs and focus on implementation, reliability, integration, or business workflow outcomes.

## Known Gap Handling

The vacancy asks for two to three years of Java development experience. The CV will not conceal this gap. It will compensate by making the depth of the Java projects easy to evaluate and by placing the most role-relevant implementation evidence prominently.

## Deliverable

A complete English CV draft ready to paste into Word or a resume template, followed by a short list of claims the candidate should confirm before submission.
